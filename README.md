# Blender vertex lock add-on
A simple Blender add-on that allows you to lock vertices, edges, or faces in place.
It prevents accidental modification during proportional editing and lets you define parts of the mesh that cannot be deleted.


## Features

- Vertex/edge/face lock
- Dedicated sidebar tab
- Customizable Shortcuts


## Compatibility
Tested on Blender 5.2.3


## Shortcuts
  - `Shift + L`: Lock Selected
  - `Alt + Shift + L`: Unlock Selected
  - `Ctrl + Shift + L`: Toggle Lock

## Installation
Either download the zip package or the repo and install the vertex_lock.py from the add-on menu. 

## How to Use

1. Enter Edit Mode on any mesh object.
2. Select parts of the mesh you want to lock.
3. Press `Shift + L` or click ''Lock Selected'' in the `Vertex Lock` N-panel tab.
4. When finished:
   - Press `Alt + Shift + L` to unlock selected geometry.
   - Or click `Unlock All` in the sidebar panel to clear all locks.
